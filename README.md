# Atividade UC3 - React

Este repositório foi criado para adicionar as atividades desenvolvidas durante a **Unidade Curricular 3 (UC3) - React**. O objetivo desta atividade foi reproduzir uma imagem de referência utilizando **React**.

## Tecnologias Utilizadas

* **React:** Para a criação da página utilizando componentes.
* **JavaScript:** Para a lógica e funcionamento da aplicação.
* **CSS:** Para a estilização e reprodução do layout da imagem.
